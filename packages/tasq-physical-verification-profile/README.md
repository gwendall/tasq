# Physical Verification Reference Profile

Private, provider-neutral reference Profile and TQ-632 certification harness.

It compiles one bounded `verify_property_exterior` order into exact target,
commitment, evidence, review, qualification, permission and stop-condition
inputs. It does not provide workers, routing, prices, access, identity,
insurance or physical truth.

The scenario certifier enforces the same target, authority, execution,
validation, recovery, portability and custody separation across six unrelated
domains. See [`TQ-632_DELEGATED_ACTION_CERTIFICATION.md`](../../docs/contracts/TQ-632_DELEGATED_ACTION_CERTIFICATION.md).
